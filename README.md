# 💰 Expense Tracker

A modern and responsive **Expense Tracker Web Application** built using **HTML, CSS, and JavaScript**.

It helps users easily manage their income and expenses, track transactions, and understand their spending through a clean and attractive dashboard.

## ✨ Features

- 💰 Track total balance
- 📈 Add income
- 💸 Add expenses
- 📝 Add transaction description
- 📂 Categorize transactions
- 📅 Select transaction date
- 🗑️ Delete transactions
- 🧹 Clear all transactions
- 📊 Spending overview
- 💡 Smart money tips
- 💾 Data saved using Local Storage
- 📱 Fully responsive design
- 🌙 Modern dark Antigravity-style UI
- ✨ Glassmorphism and gradient effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your income and expenses.

## 📊 Dashboard

The dashboard displays:

- Total Balance
- Total Income
- Total Expense
- Recent Transactions
- Spending Categories
- Smart Money Tips

## 💾 Data Storage

The application uses **Browser Local Storage**, so transactions remain saved even after refreshing or reopening the browser.
